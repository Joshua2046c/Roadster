# Roadster 车牌挂坠

单件挂坠，本体72×38×3.5 mm，四角平面半径R3，左侧凸出一体挂绳孔。本产品为纯机械挂坠，无电子元件。

## 外观要求

车牌轮廓和周边圆弧下凹槽参考用户的两张车牌照片。正面文字以用户新上传的高清黑字白底RDSTR图为依据，按其粗笔画、字距、R斜腿、D圆肩和S曲线逐字重绘，并制作饱满圆润的浮雕顶面。

周围一圈为圆弧下凹槽，内侧过渡弧度大于外侧。凹槽两侧与平面相切，槽底连续。

文字与边框之间适度增加留白。文字底部轮廓包络到凹槽内侧平面边界的水平净距，左右各约12.38 mm；竖直净距，上下各约8.70 mm。

## 已披露默认值

本体长度默认72 mm、高38 mm，宽高比约1.89∶1，按用户要求参考新增车牌照片调整比例及留白。72 mm不含左侧挂耳；总长79 mm。文字高15.5 mm，以新图字组包络比例映射后总宽约42.14 mm。文字高出本体0.6 mm，成品最大厚度4.1 mm；顶面内外周缘默认R0.45 mm圆角。字形轮廓和内孔取自新图，圆角是对图中圆润表面的几何实现，图片中的光照明暗不当作字形边界。

挂绳孔直径4 mm，挂耳外径10 mm、厚3.5 mm。圆弧凹槽深0.45 mm，槽底半径0.45 mm，外侧过渡R0.35，内侧过渡R1.2；槽宽约1.85 mm，外侧平边宽0.7 mm。截面尺寸是按用户定性要求选择的默认值。

默认银灰色PETG单件打印，平背朝下，挂绳自备。

## 验收

本体72×38×3.5 mm；外形圆角R3；单一连通实体；左侧4 mm贯穿孔；文字与高清RDSTR图对照目视检查，笔画比细线字形饱满；检查R0.45顶面圆角及周边凹槽。交付可编辑参数与当前STEP。未做实物试打。
