# RDSTR 车牌挂坠

## 目的与参考

本体72×38×3.5 mm，平面四角R3，宽高比约1.89∶1。按用户允许调整整体尺寸和比例的要求，使用 plate_spacing 照片校对文字四周留白，具体72×38 mm是披露默认值。plate_front、plate_alternate用于凹槽和车牌外观；rdstr_lettering高清粗笔画图用于文字轮廓、内孔、光学字距与圆润浮雕。

字组名义宽42.14 mm、高15.5 mm、凸起0.6 mm、顶面内外周边R0.45，竖笔画约2.8 mm、横笔画约1.75 mm。文字居中，文字底部轮廓包络至凹槽内侧平面边界，左右各约12.38 mm，上下各约8.70 mm，按水平与竖直方向计算；不包含凹槽宽度。加大的左右留白使牌面更横向舒展。

## 凹槽截面

闭合扫掠圆弧凹槽，外侧平边0.7 mm、槽深0.45 mm。外侧过渡R0.35、槽底R0.45、内侧过渡R1.2。相切圆弧连接两侧同高平面，内侧更宽缓。槽宽约1.85 mm，最薄处3.05 mm。

## 接口

cord_eye：左侧中部一体挂耳外径8 mm、通孔4 mm、径向壁宽2 mm（按用户要求减少三分之一），圆心在本体左边向外2 mm，净凸出6 mm。总包络78×38×4.1 mm。eye_root_transition 标注图对应挂环根部两侧的R2平面相切圆弧，填平连接处的凹尖角并局部加宽根部。R2为披露默认值；自由环段仍保留2 mm径向壁宽。

## Making and assembly

默认PETG打印，平背朝下，建议层高0.1–0.15 mm，无需支撑。文字顶面圆弧和凹槽适合精细切片或树脂打印。文字可在3.5 mm处换色。挂绳自备，穿过贯穿孔系结。未做实物试打或承载测试。

## 验收

对照 plate_spacing 正视检查比例与留白，斜视检查R0.45文字顶面和圆弧凹槽；数值检查本体72×38 mm、左右净距约12.38 mm、上下约8.70 mm及单一有效实体；检查根部双侧圆弧半径R2、4 mm通孔和相切衔接。交付当前STEP并刷新预览。
